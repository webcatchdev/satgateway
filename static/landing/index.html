✨ Why SatGateway?

🛡️ Non-Custodial

You hold the keys. Your node, your sats. No third-party ever touches your funds.

🏠 Self-Hosted

Runs on a $5 VPS. No platform fees, no rate limits, no vendor lock-in.

⚡ Lightning-Native

Micro-payments from 1 sat. Instant settlement. No chargebacks. Global.

🔌 Framework Agnostic

Built on FastAPI but the pattern works anywhere. Decorator, middleware, or manual.

📊 Built-in Analytics

Track revenue, conversion rates, and payment flows out of the box.

🧪 Dev Mode

Mock backend auto-pays invoices for local development. No testnet needed.

📡 API Reference

# Create an invoice

# Get QR code PNG

# Gateway health
GET /api/status
